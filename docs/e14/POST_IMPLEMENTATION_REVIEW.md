# E14 – post-implementation review

Po stabilizácii zaznamenať:

- incidenty, warningy, retry a všetky manuálne zásahy,
- priemerný čas týždennej redakcie pred a po nasadení Carla,
- počet automaticky prevzatých a manuálne doplnených udalostí,
- skúsenosť Admina a Team Moda na desktope aj mobile,
- nejasné texty, opakované kroky a accessibility problémy,
- stav záloh a výsledok najnovšej restore rehearsal,
- nevyhnutný technický dlh oddelený od voliteľných rozšírení,
- vlastníka aktualizácií závislostí, backupov, monitoringu a UAT regresie,
- dátum najbližšej bezpečnostnej a restore kontroly.

Výsledok review sa prepíše do backlogu a `STATUS.md`; nesmie spätne meniť
release manifest nasadeného buildu.
