# Etapa E1 – aplikačná kostra a vývojové prostredie

Etapa E1 vytvára prvý spustiteľný, ale ešte produktovo prázdny runtime Domček Bot 2.0. Jej výstupom sú spoločná konfigurácia, API, Discord proces, worker, PostgreSQL, migrácie, frontend a automatizované kontroly kvality.

## Hranica etapy

E1 nezavádza doménové tabuľky, synchronizáciu Google Kalendára, oznamový composer ani administračné funkcie. Tieto časti patria do E2 a nasledujúcich etáp.
