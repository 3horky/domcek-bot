# UI/UX dôkazy

Každý podpriečinok `ux0` až `ux10` môže obsahovať iba malé, stabilné referenčné dôkazy, ktoré vysvetľujú rozhodnutie alebo odhaľujú regresiu. Do Git repozitára nepatria automaticky generované Playwright traces, celé HTML reporty ani duplicitné screenshoty.

Názov stabilného obrázka používa tvar `<route>--<stav>--<viewport>.png`. Zdroj scenára, rola a akceptácia sú vždy uvedené v `../AUDIT_MATICA.md`; samotný obrázok nie je dôkazom funkčnosti.
