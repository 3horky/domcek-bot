# Autorizačná matica E5

| Schopnosť | Team Mod | SDB / FMA | Admin |
|---|---:|---:|---:|
| Dashboard a najbližší draft | áno | áno | áno |
| Obsahová úprava udalosti alebo série | áno | nie | áno |
| Manuálne udalosti a INFO oznamy | áno | nie | áno |
| Force include alebo force exclude | nie | nie | áno |
| Ručné publikovanie | nie | áno | áno |
| Vytvorenie kanála / žiadosť o archiváciu | áno | nie | áno |
| Schválenie archivácie | nie | nie | áno |
| Nastavenia, roly a úplný audit | nie | nie | áno |

Používateľ môže mať viac rolí; výsledné schopnosti sú zjednotením ich povolení.
Bežný člen nemá prístup do administrácie. Každý use case kontroluje schopnosť
samostatne a citlivá operácia používa čerstvé serverové overenie členstva.
